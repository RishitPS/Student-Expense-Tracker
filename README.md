
# Student Expense Tracker 💰

A simple console-based expense management application built using C++. This project helps students keep track of their daily expenses and analyse their spending habits.

## 🚀 Features

- **Add Expenses:** Record expenses with category, amount, and description.
- **View Expenses:** Display all recorded transactions.
- **Total Spending:** Calculate the total amount spent.
- **Category Analysis:** View spending grouped by categories.
- **Data Persistence:** Automatically save expenses to a text file so records remain available after restarting the application.

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL (Vectors and Maps)
- File Handling
- Standard Template Library

## ⚙️ How to Run

### Prerequisites
- C++ compiler (G++ recommended)

### Compilation

```bash
g++ main.cpp -o tracker.exe
```

### Execution

On Windows PowerShell:

```powershell
.\tracker.exe
```
